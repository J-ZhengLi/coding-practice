# CLAUDE.md

Project instructions for AI agents working on this codebase.

## Do Not Track .planning/

The `.planning/` directory is for local planning artifacts only. It is:

- **Git-ignored** — `.planning/` is listed in `.gitignore`
- **Off-limits for commits** — Never stage, add, or commit any file under `.planning/`
- **Readable but not writable by AI** — You may read from `.planning/` for context, but never write new files there or modify existing ones

Planning and documentation artifacts belong in version-controlled locations only.
